A Study and Implementation of Incremental Delaunay Triangulation

This repository contains my bachelor thesis project completed at Eötvös Loránd University, Faculty of Informatics, Department of Numerical Analysis.

The project is about Delaunay triangulation, a method for connecting points with triangles in a clean and well-structured way. Instead of creating long and narrow triangles, Delaunay triangulation tries to form triangles that are more balanced. This makes the result easier to use in areas such as computer graphics, maps, simulations, and visual modeling.

The thesis focuses on building the triangulation step by step. New points are added one at a time, and the triangle structure is updated after each insertion. To make the process easier to understand, the project also includes an interactive desktop application that shows how the triangulation changes visually.

The project was developed in C# with .NET 9.

What the Project Includes

This project includes:

a program that creates Delaunay triangulations from a set of points,
an interactive application for visualizing the process,
step-by-step updates showing how the triangles change,
support for displaying the related Voronoi diagram,
and tests to check that the main parts of the program work correctly.
Purpose of the Project

The goal of this thesis is to explain and demonstrate how Delaunay triangulation works in practice. The project combines theory, implementation, testing, and visualization so that the algorithm can be understood not only through formulas, but also through an interactive visual example.
